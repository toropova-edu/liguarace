# English Duel 🇬🇧 — английский вдвоём

Небольшое веб-приложение для Евгении и Богдана: у каждого свой курс на 26 недель, недельные челленджи, XP, серии, награды и дуэль друг с другом. Без сборки и серверов — обычные файлы для GitHub Pages.

## Что внутри

| | Евгения | Богдан |
|---|---|---|
| Уровень | с нуля (A0 → A1+) | слабый A2 → A2+/B1 |
| Старт | тема «Дом: комнаты и мебель» | тема «Продукты и магазин еды» |
| Слов | 737 | 904 |
| Недель | 26 (≈ полгода) | 26 (≈ полгода) |

Каждая неделя = тема + ~28–35 слов + грамматика + 5 заданий:
1. **Карточки** — знакомство со словами (озвучка).
2. **Квиз** — выбери перевод.
3. **Слушай и пиши** — диктант слов.
4. **Грамматика** — короткий урок и 9–11 упражнений (выбор, вписать, собрать предложение).
5. **Босс недели** — 16 вопросов, включая повторение прошлых тем. Нужно ≥ 60%, чтобы открыть следующую неделю.

Игры: **Повторение** (интервальные повторения по Лейтнеру), **Пары**.
Геймификация: XP, уровни, серия дней, цель на день, 3 квеста недели (+30 XP), 21 достижение, звёзды за задания.
Соревнование: **Дуэль недели** (пн–вс) по XP, сравнение статистики, кубки за выигранные недели.
Подсказки: кнопка «💡 Подсказка» в каждом вопросе (2 уровня, −50% XP за вопрос) и кнопка «📖» — словарь с поиском и все уроки грамматики в любой момент.

## Как выложить на GitHub Pages

1. Создайте репозиторий (например `english-duel`) и загрузите в него **содержимое этой папки** (файл `index.html` — в корне).
2. Settings → Pages → *Deploy from a branch* → ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/english-duel/`.

## Как включить общую статистику (любое устройство)

Прогресс хранится в файлах `data/progress/evgenia.json` и `data/progress/bogdan.json` прямо в репозитории. Приложение само читает и записывает их через GitHub API.

1. GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → *Generate new token*.
2. *Repository access* → Only select repositories → ваш репозиторий. *Permissions* → **Contents: Read and write**. Срок — по желанию (до года).
3. Откройте сайт → вкладка **Ещё** → «Облако»: репозиторий (`логин/english-duel`, обычно подставится сам), ветка `main`, токен → «Сохранить и синхронизировать».
4. Повторите шаг 3 на каждом устройстве (токен хранится только в браузере этого устройства).

Если токена нет, приложение только **читает** данные: вы увидите результаты соперника, но свой прогресс сохраняется только на устройстве.

Важно:
- Не публикуйте токен в репозитории и не отправляйте его в чатах. Токен только на один репозиторий и только Contents — его легко отозвать.
- Если репозиторий публичный, прогресс (XP, слова) виден всем, у кого есть ссылка на репозиторий. Для приватного репозитория GitHub Pages нужен платный тариф, а чтение чужого прогресса без токена не заработает — тогда введите токен на всех устройствах.
- Данные «сливаются» без конфликтов: можно заниматься с телефона и ноутбука, ничего не потеряется.
- Сбросить прогресс: удалите содержимое нужного файла в `data/progress/` на GitHub (вернув `{"v":1,"log":{},"tasks":{},"words":{},"ach":{},"upd":0}`) и очистите данные сайта в браузере.

## Для учителя

- **Вкладка «Ещё» → «Режим учителя»** открывает все недели сразу.
- Курсы лежат в `data/evgenia-*.js` и `data/bogdan-*.js`. Формат недели описан в `data/base.js`:
  - слова: `english=перевод;` через `;` или с новой строки;
  - упражнения: `c|Предложение с ___|верный|неверный1,неверный2`, `t|Предложение с ___ (подсказка)|ответ|другой/вариант`, `o|Русский перевод|English sentence`.
- Чтобы поменять тему недели, достаточно отредактировать объект `addWeek(...)`. После правок увеличьте `?v=1` в `index.html`, чтобы браузеры загрузили свежие файлы.
- Проверка файлов курса: откройте сайт — если в консоли браузера (F12) нет ошибок, формат верный.

## Локальный запуск

```bash
python -m http.server 8000
```
и откройте `http://localhost:8000`.
